what the options do
human
You play. No network, no credentials needed.
agent
A control loop owns the game: it observes state, asks a policy what to do, and acts through explicit tools, emitting events as it goes. The policy is swappable, which is what the dropdown selects.
planner
The original pre-agentic version, kept as a control to compare against. It posts the raw lane to the model every few steps and applies whatever comes back. No loop, no tools, no events, and no fallback - so unlike the agent, it really does stop working without credentials.
policy: LLM (batch plan)
One model call every 5 steps covering every visible obstacle. Each obstacle ends up covered by several successive plans, so one slow reply is harmless.
policy: LLM (per obstacle)
One model call per obstacle. Fewer wasted tokens, but no redundancy: a single late reply loses that obstacle.
policy: heuristic
Pure local code, no model. Also the automatic fallback whenever an LLM policy fails, errors, or takes too long.
seed / share
The seed fixes the lane. The same seed always generates the same obstacles, so a human run and an agent run can be compared on identical terrain. share copies a link that replays this exact run.
pause / abort
Pause freezes the world; scheduled actions survive it because the clock is counted in steps, not wall time. Abort cancels the in-flight model call and stops the agent deciding - the game keeps running until the player hits something.
